# Blackjack Card Game

A console-based Blackjack game written in Java. One player plays against a
computer-controlled dealer. 

## Team

- Ashley Myth Ban-o: Team Leader and Software Designer
- Divjot Mundi Singh: Lead Programmer

## Rules Used in This Version

- The player can Hit or Stand.
- The dealer draws until reaching 17 or higher.
- An Ace counts as 1 or 11.
- Blackjack, bust, and push are identified at the end of each round.
- Not included: betting, Double Down, Split, and Insurance.

## Repository Structure

- `code`: Java source files
- `docs`: written documents
